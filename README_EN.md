## 🧩 Featured Project

### [Gimbal-AI-Assistant](https://github.com/Z-Teddy/Gimbal-AI-Assistant)

This is an embedded intelligent agent system built on a heterogeneous **RK3588 + STM32** architecture. It integrates visual perception, offline speech interaction, local LLMs, and real-time motion control on physical hardware, forming a complete interaction pipeline from environmental perception and task understanding to device execution.

**Currently supports:**

- Face detection and visual tracking on the RK3588 NPU, with dual-axis gimbal control handled by the STM32
- Offline speech recognition, VAD, TTS, and local LLM inference for voice control, status queries, and natural language interaction
- RK3588 for vision, speech, and intelligent decision-making, while STM32 + FreeRTOS handle real-time control and hardware execution
- Device control, task scheduling, status feedback, and fault handling, enabling a complete interaction loop between AI and physical hardware
