## 🧩 Featured Project

### [Gimbal-AI-Assistant](https://github.com/Z-Teddy/Gimbal-AI-Assistant)

这是一个基于 **RK3588 + STM32** 异构架构的嵌入式智能体系统，尝试将视觉感知、离线语音、本地大模型与实时运动控制整合到真实硬件中，实现从环境感知、任务理解到设备执行的完整交互链路。

**目前支持：**

- 基于 RK3588 NPU 实现人脸检测与视觉跟踪，并通过 STM32 完成双轴云台实时控制
- 集成离线语音识别、VAD、TTS 与本地 LLM，实现语音控制、状态查询和自然语言交互
- RK3588 负责视觉、语音与智能决策，STM32 + FreeRTOS 负责实时控制与硬件执行
- 设计设备控制、任务调度、状态反馈与异常处理流程，使 AI 能够与实际硬件形成闭环
